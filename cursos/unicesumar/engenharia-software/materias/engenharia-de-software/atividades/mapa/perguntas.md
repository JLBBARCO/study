# Questão 1

**A empresa Conecta Saúde deseja desenvolver um aplicativo para marcação de consultas médicas. O sistema deverá permitir que pacientes cadastrem seus dados, pesquisem médicos por especialidade, agendem consultas, recebam notificações e avaliem o atendimento.**

**A diretoria decidiu utilizar Scrum, pois o projeto possui mudanças frequentes, necessidade de entregas rápidas e participação constante dos usuários. A primeira Sprint terá duração de 2 semanas e deverá entregar uma versão inicial funcional do aplicativo.**

**Você foi convidado a apoiar a organização do projeto Scrum.**

Com base no estudo de caso apresentado, preencha o quadro a seguir, relacionando os elementos do Scrum às atividades práticas do projeto.

| **Elemento do Scrum**   | **Aplicação prática no projeto Conecta Saúde** |
| ----------------------- | ---------------------------------------------- |
| Product Owner           |                                                |
| Scrum Master            |                                                |
| Time de Desenvolvimento |                                                |
| Backlog do Produto      |                                                |
| Backlog da Sprint       |                                                |
| Sprint                  |                                                |
| Daily Scrum             |                                                |
| Sprint Review           |                                                |
| Sprint Retrospective    |                                                |
| Incremento funcional    |                                                |

Após preencher o quadro, escreva um texto discursivo, máximo de 10 linhas, explicando como os elementos do Scrum contribuem para organizar o desenvolvimento do aplicativo Conecta Saúde. Em sua resposta, destaque a importância dos papéis, dos eventos, dos artefatos e das entregas incrementais para garantir colaboração, transparência, adaptação e geração de valor ao cliente.
